# E6: Qwen Experience With DeepSeek Evolver

Status: defined, not launched. Added by user on 2026-10-09.

E6 uses Qwen's own raw experience to generate and evolve a reusable Skill
library with DeepSeek. Qwen remains the task executor. It uses the same
progressive library procedure as E1, rather than the historical single
bootstrap procedure used by E3/E5.

## Model And Data Roles

| Role | E6 |
| --- | --- |
| Raw experience | E1 source: 89 tasks x 3 Qwen no-Skill rollouts |
| Library proposal / cold start | DeepSeek, model ID DEEPSEEK_up5zdj |
| Evolution planner and editor | DeepSeek, model ID DEEPSEEK_up5zdj |
| Predicted gate reviewer | DeepSeek, model ID DEEPSEEK_up5zdj |
| Runtime selector | Qwen, qwen3.6-flash-distill |
| Task executor | Qwen, qwen3.6-flash-distill |

Here Evolver includes initial library generation, planner, editor and reviewer.
Library size is model-generated from the evidence, not fixed to E1's seven
Skills. E6 does not import E1's final library or historical E3/E5 bootstrap
libraries. Changing the generator and reviewer means the comparison measures
the whole DeepSeek evolution pipeline, not only the editor model.

## Procedure And Acceptance

1. Import the 267 original Qwen rollouts, preserving task/attempt identity,
   trajectory paths, exceptions and source-model provenance.
2. Build 89 task experience cards and generate an initial library from them,
   using E1's proposal procedure without predefined task membership.
3. Route with a metadata-only catalog, then load one selected Skill body.
4. Execute one evolution round with at most three task attempts, using E1's
   progressive routing, card construction, family batching and acceptance
   panel construction. Do not substitute a general bootstrap and 50/39 split.
5. Commit only when predicted candidate_mean > base_mean. Record all holds.
   Predicted scores are not actual verifier pass rates.

All 89 tasks are train/evolution; acceptance is closed-set, not independent
validation/test generalization. Formal requests use Tencent E2B relay, task
persistence=0, and total active workers across experiments must not exceed 100.
DeepSeek requests use thinking, stream and max_tokens=65536. E6 requires a new
run directory, manifest, status, PID, journal, result, coverage and audit.
Definition does not authorize an immediate launch or change running stages.

## Comparison

- E1: Qwen raw experience, Qwen library generator/Evolver, Qwen execution.
- E6: Qwen raw experience, DeepSeek library generator/Evolver, Qwen execution.
- E5: Qwen + DeepSeek mixed raw experience; E6 uses only Qwen raw experience.

Actual verifier evaluation of a frozen final E6 library is a separate stage.
Do not claim an uplift unless baseline coverage and execution settings are
comparable and the empirical audit is complete.
