## Cold Start and Evolution

- Input audit verifies source model and unique source/task/attempt identities.
  Each trajectory/result path remains traceable. Raw timeout acceptance and
  the explicit Qwen exception waiver do not establish complete verifier scores.
  Unknown raw rewards stay null in the raw ledger.
- 89 discovery cards are built from raw inputs. E5 retains six trials per task,
  selecting equal evidence counts per source without substituting missing data.
- The E1 proposal and materialization scripts freely generate and freeze v0
  Skills. One generated Skill is permitted; an automatic bootstrap is forbidden.
  Task assignment tables are forbidden. Catalog excludes Skill bodies.
- Each of 267 independent execution slots selects then loads one Skill. Three
  canary tasks run once before the full panel and count toward coverage. Only
  strict verifier results are accepted; infrastructure failures remain separate.
- Independent selectors must agree within a task before the existing one-family
  experience schema can aggregate its three trials. Disagreement is reported as
  needs_attention, preserving all valid slots rather than silently mixing families.
- New cards feed the existing E1 family evolution loop: one round, up to50 cards
  per batch, three candidate hypotheses, body rewrite, frozen descriptions and
  L3 disabled.
  The frozen family routing panel and strict candidate_mean > base_mean gate
  are preserved. Predictions are not verifier pass rates.
