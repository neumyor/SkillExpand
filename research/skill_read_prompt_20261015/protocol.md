# Prompt-Only Skill Reading Preregistration

Freeze before calls: complete unmodified ten-Skill E6 final library plus the
unmodified newly generated Git initial package (11 entries), public development
tasks fix-git and log-summary-date-ranges, common prior loading runtime,
Qwen/provider/context/thinking/environment/verifier and offline judgment rules.
No generation, library editing, external selection, task-to-Skill mapping,
body injection, automatic reading or tool enforcement. Only query tail varies.
The explicit tail requirement overrides the historical optional catalog wording.

Development v1: one execution per task. If both verifiably return substantive
Skill body to the model before any task operation, freeze v1 immediately.
Otherwise run v2 once per task; select highest count of reading/order passes,
ties prefer v1. Official task rewards never select prompts. Unresolved stays
unknown, consumes its slot and cannot be replaced. Maximum development four.

Acceptance after selection: new independent fix-git, logs, fix-git, logs,
fix-git slots (five total). Freeze selection before dispatch; no final feedback
can change it. All five must verifiably pass. A partial or unresolved batch
does not pass. Absolute cap nine Qwen executions, no retry/replacement.

Reading requires actual terminal read call naming a mounted SKILL.md and at
least two substantive non-frontmatter body lines, totaling >=120 characters,
in both its tool observation and a subsequent model input. The read's entire
command batch must contain only directory navigation/viewing or Skill-file
reading; no task operation may precede the next model input containing body.
Conservative shell classification: ambiguous commands are substantive until
manually reviewed against retained commands/observations. Path mentions, plans,
ls, metadata-only reads and kernel access alone cannot pass. Partial reads may
pass only when they contain substantive body, not just metadata. Keep exact
commands, observations, request indices, step IDs and first task operation.

Audit all initial query tails, full 11-entry catalogs, mounted bytes, effective
parameters, unique sandbox identities, frozen file bytes and official rewards.
Report task score independently of reading. Environment failures are unresolved,
not reading failures/successes. Prior four-run results are diagnostic only.

E11 prerequisites: substantive initial-generator acceptance, this new frozen
five-run reading acceptance, and complete E10 archive. Do not start E11 while
any prerequisite is unverified. Root Codex gpt-6.1-sol/high is requested but no
switch/verification API is available; do not claim it was switched.
