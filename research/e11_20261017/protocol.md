# E11 Frozen Registration

Authorized 2026-10-17. This is a closed-set, multiple-module experiment using
historical experience on all 89 evaluation tasks. It cannot establish unseen
transfer or the causal contribution of a single module.

The source panel is the completed E10 RPC-repair full rerun: 267 logical slots,
116 official ones, 147 official zeroes and four user-policy derived zeroes.
Original result files, raw trajectories, failed retry archives and the scoring
amendment are copied without alteration. Derived scores remain separate from
official rewards. Old E10 registrations are preserved as provenance, never
rerun. Generation sees public task instructions and legal tool observations,
not verifier files, hidden tests, model reasoning, researcher diagnoses or old
research candidates. Restricted tool steps are recorded as removed, not empty
successful evidence. There is no character truncation. Large inputs are split
only at tool-step boundaries, preserving trial and step ordering.

The eleven routing scopes are frozen from the accepted complete catalog. Only
their IDs, names and descriptions are used for generic routing; the frozen
seed packages provide the initial package state and are not treated as new
task-specific evidence. DeepSeek assigns each
public task contract to one or more scopes using routing metadata only. This
generation-only assignment is never supplied to the executor. All assigned
observations are processed in deterministic task/trial/step order. The frozen
seed package for each scope is then passed through one sequential native
SkillEditor.propose_package evolution pass.
Model-generated packages are never manually edited. No-change retains the
current package. Invalid generation stops the pipeline and retains evidence.
Routing and editor requests have one call. No transport retries or budget
resets.

Development has zero Qwen slots, zero reward-based candidate selection, and
one generic evolution pass from the frozen seed packages. For N frozen
evidence chunks, routing has 89 calls and evolution has at most N calls, so the
maximum is 89+N DeepSeek calls, frozen after mechanical chunking and before the
first model call. The actual smaller assignment schedule is frozen after
routing and before editing. Every scope must receive evidence or the run
stops. Evolution uses full packages, optional resources and native package
validation. Pattern claims are proposals, not empirical acceptance. There is
no fresh development feedback. E10 remains historical input; no E11 final
outcome is returned to generation, and there is no post-final optimization.

After generation/evolution, freeze exactly eleven complete packages and the
catalog. Executor receives IDs/descriptions and entrypoint locations only and
autonomously decides whether/when to load one or more Skills/resources. First
user query ends with the authorized optional hint:
`你可以读取 /opt/openclaw-skills 下的 skill。`
No external selector, task-to-Skill execution mapping, automatic reader,
body injection or mandatory-reading gate is used. The previous forced-first-cat
study is prerequisite evidence, not this experiment's loading configuration.

Formal budget: 89 tasks x 3 attempts = 267 logical Qwen slots, one formal job.
Harbor max_retries=1 is inherited from E10; at most 534 physical executions.
Every failed physical execution is archived. No manual retries, replacement
slots, extra smoke runs or old experiment reruns. Concurrency 100; agent budget
7200 seconds. Requested executor qwen3.6-flash-distill, input 262144, output
65536, top_p=.95, top_k=20, thinking/interleaved/preserve enabled, summarize
threshold 8000, ModelBest .co/v1. All other model roles DEEPSEEK_up5zdj.
Environment, task snapshots, verifier/cache policy and RPC-repaired adapters
are frozen from current E10 runtime. Only library mounting, catalog exposure,
optional user-query hint and required job/path identifiers differ.

Official rewards, execution exceptions, verifier evidence and environment
unresolved status remain distinct. The four E10 derived zeroes are not a policy
for future E11 errors. Final audit checks complete task coverage, actual model
requests/configuration, package bytes and loading traces. A submission, process
start or directory is not experiment completion.
